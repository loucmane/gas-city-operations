## Run order

Each step runs once, as
`systemd-run --user --wait --collect --pipe --quiet -p UMask=0022 /usr/bin/python3 -I -S -B <p12>/source-launch.py <p12>/<script> <sha256>`:
1. Get two SOURCE_PASS reviews of this package.
2. Run `p12-input.py`.
3. Run `p12-observe-compose.py`.
4. Run `p12-readiness.py`.
5. Fill the five adoption constants. Commit, then get two reviews.
6. Run `p12-adopt.py`.
7. Get two adoption readback reviews.

**Quiescence** runs from step 2 until the adoption log:
- no gc except the scripts' own reads;
- no `workflow.py`;
- no Bead write;
- nothing routes to or unsuspends an agent.

**Stop conditions.** Stop on any of these, and never re-run into a consumed root:
- any refusal;
- host epoch drift;
- a revision other than `06076790`;
- a controller pid other than 2800348;
- composition drift from the draft for any profile;
- a preflight or negative result other than the dry proof's;
- an authentication posture other than subscription;
- a pinentry prompt;
- drift outside the receipt.

**Rollback.** `p12-adopt.py` restores the exact old bytes 06a3f58a automatically, and only after clean containment. An unknown receipt image is preserved and stops the run.
